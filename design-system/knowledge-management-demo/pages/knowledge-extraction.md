# Knowledge Extraction · Page Override

- The task has only two user decisions: select one qualified knowledge set and select one IT-built graph Schema.
- Graph Schemas are read-only assets designed offline by domain experts and technically validated and embedded by IT.
- Selecting a Schema immediately updates a compact visual preview of its knowledge type, entities, core attributes, relations, version, and publication state.
- Do not expose model creation, field editing, document-level picking, batch defaults, or task-save controls on this page.
- Keep one primary action: start the knowledge extraction task using the selected knowledge set and Schema.
